Dayscreen

Dayscreen is a personal home-automation project: a small e-paper display that shows the day's schedule, weather, and household information on a single screen.

It reads a Google Calendar belonging to the developer, using the read-only calendar.readonly API scope, purely to display that calendar's events on the physical device. It does not write to, modify, or share calendar data with any third party.

This is a single-user, personal-use application. It is not distributed, not offered as a service to others, and has no other users besides its developer.

Privacy

Calendar data retrieved via the Google Calendar API is used only to render the display and is not stored beyond what's needed for that rendering, not sold, and not shared with any third party.
